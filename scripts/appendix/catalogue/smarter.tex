implicit hate, which kind (for example, irony or stereotyping).

\{<<q:smarter_latent_hate:question.criteria|keys>>\} in Latent Hate and \{<<q:smarter_implicit_hate:question.criteria|keys>>\} in Implicit Hate.
@example frozen HateXplain test set (MIT, item \texttt{<<jl:data/frozen/smarter/hatexplain.jsonl:420.id>>})
