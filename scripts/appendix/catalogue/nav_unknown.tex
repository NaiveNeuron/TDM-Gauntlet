@task
Recognise what a user wants from a short request to a virtual assistant, or say that the request falls outside the
intents the assistant knows. Half of the intents are hidden, so their requests must be recognised as unknown.
@output
One of the partition's known intents (<<s:nav_unknown/clinc150:per_partition.0.n_id_intents|int>> for CLINC150,
<<s:nav_unknown/banking77:per_partition.0.n_id_intents|int>> for BANKING77, intent names only) or
\textsc{<<q:nav_unknown:fallback_label>>}.
@example frozen CLINC150 test set (CC BY 3.0, item \texttt{<<jl:data/frozen/nav_unknown/clinc150.jsonl:3.id>>})
Utterance & <<jl:data/frozen/nav_unknown/clinc150.jsonl:3.text|c220>>
Gold & <<jl:data/frozen/nav_unknown/clinc150.jsonl:3.intent>> (\textsc{<<q:nav_unknown:fallback_label>>} in partitions where this intent is held out)
@sets
nav_unknown/clinc150 = CLINC150 (ID+OOD) | | macro-F1
nav_unknown/banking77 = BANKING77 (ID+OOD) | | macro-F1
